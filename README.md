# 📊 Task 2: Superstore Sales Data Analysis

## 📌 Overview
This repository contains the **Superstore Sales Data Analysis** project completed as part of the **Data Science Internship at Synent Technologies**. The goal of this task is to perform Exploratory Data Analysis (EDA) on retail sales data to understand revenue distributions, profit margins, and top-performing product categories.

---

## 🛠️ Tech Stack & Tools
- **Language:** Python 3.x
- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Seaborn, Matplotlib
- **Environment:** Google Colab / Jupyter Notebook

---

## 📌 Key Highlights & Insights
- **Sales vs Profit Analysis:** Analyzed performance across `Furniture`, `Office Supplies`, and `Technology` categories.
- **Top Performing Category:** `Technology` emerged as the highest revenue and profit-generating segment, primarily driven by `Phones` and `Copiers`.
- **Steady Volume:** `Office Supplies` maintained high order volume with consistent profit margins.

---

## 📊 Visual Output Highlights
- **Category Performance Bar Chart:** Visualizing total sales and profits side-by-side.
- **Sub-Category Sales Chart:** Highlighting top revenue contributors across product lines.
